# Design history

PlugWarden 2.0 was rebuilt from scratch in September 2026 through repeated design → critique rounds.
These are the working documents from that process, kept for context:

- [`BRIEF.md`](BRIEF.md): the original rebuild brief (jobs-to-be-done, information architecture, API contract).
- `critique-r1.md` … `critique-r8.md`: independent UI/UX reviews after each round (6.5 → 9.5/10). Screenshot paths refer to working files that aren't part of the repo.
- [`security-review.md`](security-review.md): the pre-release security review. Every finding in it has since been fixed and covered by tests.

The API contract in `BRIEF.md` is historical; the code is the source of truth.
